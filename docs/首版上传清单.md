# 首版上传清单

## 保留在 GitHub

- `README.md`、运行说明、代码索引与来源记录。
- `firmware/`：完整固件源码快照和上游许可证，不包含嵌套 Git 仓库、SDK、下载组件与编译目录。
- `server/`：完整服务端源码快照和上游许可证，不包含个人运行配置、训练数据库、录音和日志。
- `server-config.example.yaml`：无真实密钥的配置模板。
- `app/攀搭App.html`：当前 App 原型。
- `tests/run_store_checks.py` 及其调用的三组存储回归用例。
- `scripts/`：本地配置、站点构建及公开文件检查工具。
- `06_参赛产品方案.md`、`06_攀搭产品方案_PDF精排版.html`、`06_攀搭产品方案_PDF精排版.pdf`。
- `产品展示.png` 与正式方案实际引用的图版。
- 首页、GitHub Pages 工作流及 Git 忽略规则。

## 仅保留在电脑

| 内容 | 原因 |
|---|---|
| 早期 01–05 文档、旧时间表、详细参考稿 | 部分型号、模型和状态已过时；对外入口以 README 与正式方案为准 |
| App 几十个历史 HTML 版本 | 重复原型，由 Git 从当前版起记录历史 |
| 旧服务端补丁副本、旧配置、测试音频和压缩包 | 已汇总为完整 `server/` 快照；避免混淆与大文件 |
| 原机完整 Flash 备份 | 用于本地恢复，可能包含配网及设备身份数据 |
| 旧连续版报告、旧 PDF、Netlify 上传文件夹 | 首版只发布当前精排版，避免重复下载入口 |
| 未被正文引用的截图、旧图、原始照片与渲染中间文件 | 正文中的图版已自包含必要图片 |
| 截图 / 渲染 / 排版开发脚本、一次性 CLI 安装脚本 | 绑定作者电脑环境，不属于产品运行代码 |
| 依赖真实服务或个人路径的在线联调脚本 | 首版保留可隔离运行的存储回归入口 |

这些内容只从上传清单排除，未从电脑删除。

## 后续上传前

运行 `python scripts/build_site.py` 和 `python scripts/check_public_files.py`。检查命令也会验证：旧目录未被强行暂存、报告引用文件确实包含在上传候选中。

源码快照与原运行目录相互独立。后续继续在原运行目录开发时，提交前应先比较差异并同步到 `server/` / `firmware/`，不要用旧副本覆盖新改动。
