# 运行说明

## 1. 这次整理的来源

实际服务端原先位于 `~/panda-server/xiaozhi-esp32-server-main/main/xiaozhi-server`；固件源码位于 `~/panda-firmware/xiaozhi-esp32`。本仓库的 `server/` 与 `firmware/` 是独立快照，包含当时尚未提交的固件改动，原运行目录未修改。

源代码出处见 `SOURCE_SNAPSHOT.json`。上游原始源码、许可证均保留；个人配置、数据库、录音、模型下载缓存、SDK 与编译结果不在快照中。

## 2. Python 服务端

1. 创建 Python 3.10 虚拟环境，安装 `server/requirements.txt`。
2. 安装 `ffmpeg` 与 `libopus`。项目现有 Mac 开发环境使用 Miniforge；其他平台按上游说明安装。
3. 在根目录执行 `python scripts/configure_server.py --host 192.168.x.x`，按提示输入 Step API Key。
4. 执行 `python server/app.py`。如上游组件要求工作目录位于服务端，请进入 `server/` 后执行 `python app.py`。
5. 设备与电脑连接同一个支持 2.4 GHz 的 Wi-Fi。设备 OTA 地址填写 `http://电脑IP:8003/xiaozhi/ota/`。
6. 换网络后更新 `server/data/.config.yaml` 中 `server.websocket` 和设备 OTA 地址。

首次启动可能需要下载 VAD 等模型资源。公司 VPN、防火墙、热点隔离会影响本地设备连接。

配置中的 `StepASR` 使用 `stepaudio-3-asr-max`；产品报告是设计材料，模型名称以当前配置为准。

## 3. 固件

固件使用 ESP-IDF 6.x。不要直接上传设备完整 Flash 备份：其中可能包含 NVS 配网及设备身份信息。

在配置好的 ESP-IDF shell 内，从 `firmware/` 执行：

```bash
python scripts/build.py --list-boards
python scripts/build.py m5stack/stick-s3 --name m5stack-stick-s3
```

依据实际串口完成烧录。编译成功与硬件现场验证是两件事，按键、断网重连、三秒改按、显示与音频需要连设备检查。

设备上的攀搭行为（10/19 加）：

| 情况 | 设备怎么做 | 要不要联网 |
|---|---|---|
| 按键记录 | 正面短按 = 失败，侧面短按 = 完攀，正面长按 0.5 秒 = 按住说话；3 秒内再按 = 改按 | 断网先存，连上补发 |
| 运动数据 | 每次尝试当场算下落高度 / 落地冲击 / 攀爬和休息时长 / 晃动 / 流畅度，随按键上传 | 跟按键一起 |
| 重摔（冲击 ≥ 8g） | 黄屏「还好吗？按任意键=没事」+ 长震 2 下 | 断网也震；联网时小搭多说一句 |
| 摔后不动（30 秒） | 红屏闪烁 + 持续震动，10 秒内没按键就放报警音（音量最大），任意键取消 | 报警不依赖网络 |
| 训练中 30 分钟没按键 | 长震 1 下 + 问「今天结束了吗？」 | 要联网 |
| 开机 / 连上网 | 短震 1 下 | — |

IMU 阈值（`panda_motion.h` 里的常量）都是初始值，第一次去岩馆实测后按现场情况调。没装马达或 IMU 初始化失败时，其他功能照常，只是少了振动 / 运动数据。

## 4. App 与网站

`app/攀搭App.html` 是可交互的手机网页原型。

**接真实数据**：服务端起来后，手机和电脑连同一网络（岩馆里用手机热点），打开 `http://电脑IP:8003/panda/` 就是真实数据的 App：今天、复盘、线路、成长、我的全部来自数据库，能改记录、加笔记，看板聊天走 Step 大模型（和设备上的小搭同一个人设、同一份训练档案）。可以用 `?device=设备号` 看指定设备，`?api=http://电脑IP:8003` 指定服务端地址。

**演示模式**：直接打开 HTML 文件或在 GitHub Pages 上打开时连不到服务端，自动用内置演示数据，不报错。GitHub Pages 只承载静态页面，不运行 Python，也不会自动让设备服务端上云。

执行 `python scripts/build_site.py` 生成 `.site/`：仅含首页、App、报告、PDF 与展示图片。Pages 工作流只发布该目录，不发布整个源码仓库。

## 5. 报告文件

仓库提供当前正式 Markdown、精排 HTML / PDF 以及正文引用的自包含图版。图片渲染、截图和排版开发脚本含个人环境路径，保留在原电脑，未作为可移植构建工具发布。报告更新后，替换精排 HTML / PDF，再构建站点。
